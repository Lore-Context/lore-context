# Lore Context v2.0.0 Release Notes

`v2.0.0` was the PMF Closure release line that moved the hosted product toward self-serve SaaS readiness.

Public OSS boundary:
- Open-source packages include the local-first SDK, memory, eval, middleware, code-indexer, and dashboard scaffold surfaces that are safe to run without hosted production credentials.
- Hosted billing, abuse controls, AWS production operations, live Stripe setup, and tenant operations remain commercial/private surfaces.

For the public changelog summary, see [CHANGELOG.md](../../CHANGELOG.md#v200--2026-05-12-shipped).
