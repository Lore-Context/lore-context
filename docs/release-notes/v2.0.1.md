# Lore Context v2.0.1 Release Notes

`v2.0.1` corrected the commercial-closure runtime gap from `v2.0.0` by adding the quota, metering, overage, and downgrade runtime paths used by the hosted service.

Public OSS boundary:
- The hosted billing runtime and Stripe-coupled quota enforcement are intentionally not part of the OSS sync.
- Public code may reference compatible SDK and local development surfaces, but live commercial billing behavior stays private.
