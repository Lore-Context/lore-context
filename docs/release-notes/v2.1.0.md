# v2.1.0 - Repo Graph API and MCP Tools

**Status**: SHIPPED. v2.1.0 is deployed to AWS production and the public
website from final deployed SHA
`665e6020bb2920453dc02bfb60a73be21e865bbb`.

**Theme**: Make Lore's own repository graph a first-class memory surface for
agents. The release adds deterministic repository indexing, repo-graph API
queries, symbol context, impact analysis, change detection, and read-only MCP
tools so agents can ground repository answers in a stable project context
contract instead of ad hoc text search.

## Added

- `@lore/repo-graph`: deterministic TypeScript/JavaScript repository indexing
  for files, symbols, imports, calls, routes, tests, and process hints.
- API routes:
  - `POST /v1/repo/graph/query`
  - `POST /v1/repo/symbol/context`
  - `POST /v1/repo/impact`
  - `POST /v1/repo/detect-changes`
- MCP tools:
  - `repo.graph_query`
  - `repo.symbol_context`
  - `repo.impact`
  - `repo.detect_changes`
- Additive Postgres storage/view support in
  `apps/api/src/db/schema-v21-repo-graph.sql`.
- Provider-backed `context_query(repo)` evidence with an honest unavailable
  fallback when repo graph storage is not configured.

## Changed

- `scripts/release/prod.mjs` applies the additive repo graph schema during
  production/staging schema setup.
- The release train uses the optimized v2.0.9 deployment guardrails: split API
  and website production workflows, preflight blockers/warnings, and arm64-first
  production artifacts.
- Root and API package versions report `2.1.0`, keeping `/openapi.json` aligned
  with the production tag target.
